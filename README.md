# No es tan sencillo

Canal de divulgación económica y social para España. Investigamos preguntas complejas sin decidir la conclusión de antemano.

## Episodios

- [01 · Pepi y Laura](episodes/01-pepi-y-laura/): ¿Quién crea realmente un puesto de trabajo?
- [02 · Salario mínimo](episodes/02-smi/): ¿Qué ocurre cuando sube el SMI?
- [03 · Vivienda](episodes/03-vivienda/) (candidato a publicarse primero; número provisional): si hay 1,4 viviendas por hogar, ¿cómo pueden faltar viviendas?

## Método

Research → Question map → Contradiction review → Guion → Visual inventory → Producción → Revisión de fuentes.

La metodología editorial está en [docs/editorial.md](docs/editorial.md).

Del guion y los visuales al vídeo final (voz con ElevenLabs, sincronización, cartelas, render 4K y `youtube.md`): [production/README.md](production/README.md). `npm run video -- 03-vivienda all`.
